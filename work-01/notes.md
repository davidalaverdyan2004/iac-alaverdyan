# Журнал ручных действий — практика 1, вариант 04

Машина alaverdyan-04-web-manual, созданная через веб-консоль Яндекс Облака.

## Создание машины в веб-консоли

1. Открыть https://console.yandex.cloud, выбрать каталог default.
2. Перейти в Compute Cloud → Виртуальные машины → «Создать виртуальную машину».
3. Ввести имя alaverdyan-04-web-manual.
4. Нажать «Добавить метку», задать created-by = console.
5. В блоке «Образ загрузочного диска» выбрать Ubuntu 24.04.
6. Выбрать зону доступности ru-central1-a.
7. В блоке «Диски» сменить тип диска с SSD на HDD.
8. Задать размер диска 15 ГБ.
9. В блоке «Вычислительные ресурсы» открыть вкладку «Своя конфигурация».
10. Оставить платформу по умолчанию, указать 2 vCPU.
11. Выбрать гарантированную долю vCPU 20 %.
12. Указать RAM 2 ГБ.
13. Отметить «Прерываемая».
14. В сетевых настройках оставить подсеть default-ru-central1-a.
15. Публичный адрес — «Автоматически».
16. Способ доступа — SSH-ключ, логин student.
17. Нажать «Добавить ключ», вставить содержимое ~/.ssh/id_ed25519.pub, имя ключа alaverdyan-04-wsl.
18. Выключить «Резервное копирование».
19. Проверить расчёт стоимости справа.
20. Нажать «Создать ВМ», дождаться статуса Running.

## Настройка веб-сервера руками

21. Скопировать публичный IP машины из консоли.
22. Подключиться по SSH: student@<IP>, подтвердить отпечаток (yes).
23. Обновить список пакетов (apt update).
24. Установить nginx (apt install nginx).
25. Проверить, что служба nginx запущена (systemctl status nginx).
26. Открыть http://<IP> в браузере — стартовая страница nginx.
27. Отключить разбор истории bash (set +H).
28. Заменить «Welcome to nginx!» на «devlab on <имя хоста>» (sed).
29. Обновить страницу в браузере, проверить замену.
30. Выйти с машины (exit).
